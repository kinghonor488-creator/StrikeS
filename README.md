# STRIKE-S! 墨水爆破

5V5 爆破射击网页游戏（Three.js）：CS2 式的写实画面和硬核枪感，加一点漫画风的趣味。地图「墨水街」，涂鸦帮（T，进攻）对橡皮擦（CT，防守），先赢 7 回合，第 6 回合后换边。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5273 。

## 枪感（参照 CS2）

- **21 把枪 + 刀**：手枪、冲锋枪、霰弹枪/机枪、步枪、狙击枪，T/CT 各有专属枪。每把都有独立的伤害、射速、穿甲、射程衰减、移速和击杀奖励。
- **固定弹道**：每把枪都有自己的压枪轨迹（例如 K-47 的上跳加左右 S 形），第一发准、连射可以练出来。准星只跟随一部分后坐力，子弹走完整弹道。
- **精度受状态影响**：站立 / 蹲下 / 静步 / 跑动 / 空中 / 落地都会改变散布，准星间隙实时显示当前精度；急停后精度会快速恢复。
- **伤害**：部位倍率（头 ×4、胸 ×1、腹 ×1.25、腿 ×0.75），护甲和头盔分别减伤；子弹可以穿透薄掩体和墨墙；中弹会被减速。
- **经济**：胜负奖励、连败补偿、不同枪的击杀奖励；机器人会按经济做起枪 / 强起 / 存钱的决策。

## 本作的特色

- **墨水玩法**：墨墙（画一笔立起能挡子弹的墙）、墨云（遮挡视线的烟）、涂鸦标记（队友可透视看到）。墨水来自回合起始、击杀和商店。
- **手绘贴纸**：在军械库里画贴纸，点击 3D 枪身印上去；第一人称、第三人称和喷漆都会用到。
- **漫画趣味（可在设置里关闭）**：爆头和多杀时右侧弹出小漫画格、拟声字；每局结束自动排版成一页战报漫画，可保存为 PNG。

## 画面与音效

- 写实渲染管线：PBR 程序化材质、柔和阴影、环境光遮蔽（GTAO）、只作用于高光的泛光、ACES 色调映射和调色。设置里有低 / 中 / 高 / 极高四档画质。
- 特效：枪口焰与光照、曳光弹、弹壳物理、按材质区分的弹孔和碎屑（混凝土、金属、木头、墨水）、爆炸和墨云粒子。
- 音效全部用 Web Audio 实时合成：每类枪有不同的枪声，距离越远越闷、混响越多；还有分段换弹声、弹壳落地、子弹掠过、爆头声和爆炸耳鸣。

## 写实枪模

- 铅笔头 P-25 和鸟笔 S-08 使用 [Poly Haven](https://polyhaven.com) 的 CC0 模型（service_pistol、bolt_action_rifle_7_62，作者 Mateusz Sadek），游戏用的压缩版本在 `public/models/guns/`（2k 原始文件不随仓库提供，可从 Poly Haven 重新下载到 `assets/guns_src/`）。
- 接入方式见 `src/game/guns/imported.js`：每把枪配置握把、护木、枪口、抛壳口等锚点，以及套筒、枪栓、弹匣这些可动零件；模型文件缺失时自动退回代码建模。
- `tools/fetch-guns.mjs` 可以按 `tools/gun-sources.json` 从 Sketchfab 批量下载 CC-BY 枪模（需要 Sketchfab API token）。
- 开发预览：`/dev/import.html?file=/models/guns/<目录>/<文件>.gltf` 用 1 cm 网格显示原始模型，方便量锚点。

## 代码结构

- `src/render/` 渲染管线、天空与环境光、程序化 PBR 贴图
- `src/world/` 地图数据、建图、街头涂鸦、碰撞、导航网格
- `src/game/` 角色与移动、武器数据、枪模（`guns/`）、第一人称手臂、人物骨骼、机器人 AI、回合规则、墨水系统、贴纸、特效
- `src/ui/` HUD、商店、军械库、菜单、漫画格与战报
- `src/audio/` 音效合成与混音

调试：`http://localhost:5273/?debug&side=T`（或 `side=CT`、`diff=easy|normal|hard`）直接进入对局，不需要锁定鼠标。枪模预览：`http://localhost:5273/dev/guns.html?id=k47,m4`。
